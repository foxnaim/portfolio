Tact: учёт времени через Telegram и QR.

Прототип системы для команд и фрилансеров: отметка начала работы через Telegram или QR-код, таймер и данные для последующей аналитики.

Посмотреть исходный код

Задача

Что нужно было показать

Объединить быстрый пользовательский сценарий и техническую основу продукта: интерфейс, API, роли и хранение данных должны развиваться как единая система.

Решение

Как устроен концепт

Проект разделён на frontend и backend. Интерфейс отвечает за рабочие сценарии и аналитику, серверная часть — за пользователей, события и данные учёта.

Что реализовано

  • Telegram-сценарий
  • Меняющиеся QR-коды
  • Таймер рабочего дня
  • Интерфейс команды
  • API и база данных
  • Основа аналитики
