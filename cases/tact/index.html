Tact: учёт времени через Telegram и QR.

Прототип системы для команд и фрилансеров: отметка начала работы через Telegram или QR-код, таймер и данные для последующей аналитики.

Посмотреть исходный код

Задача

Что нужно было показать

Объединить быстрый пользовательский сценарий и техническую основу продукта: интерфейс, API, роли и хранение данных должны развиваться как единая система.

Решение

Как устроен концепт

Проект разделён на frontend и backend. Интерфейс отвечает за рабочие сценарии и аналитику, серверная часть — за пользователей, события и данные учёта.

User flow

Сценарий от входа до результата

  1. 01

    Сотрудник получает актуальный QR-код или открывает Telegram.

  2. 02

    Начало и завершение работы фиксируются через API.

  3. 03

    Команда видит историю и данные для учёта времени.

Решения

Почему интерфейс устроен так

  • Меняющийся QR-код снижает повторное использование
  • Telegram сокращает путь до рабочего действия
  • Frontend, API и хранение данных разделены

Границы

Что этот кейс не обещает

  • Публичная production-демонстрация не размещена
  • Правила расчёта требуют адаптации под компанию
  • Инфраструктура и нагрузка не проходили клиентский аудит

Что реализовано

  • Telegram-сценарий
  • Меняющиеся QR-коды
  • Таймер рабочего дня
  • Интерфейс команды
  • API и база данных
  • Основа аналитики
