# План аналитики портфолио

Аналитический слой работает без внешних запросов, пока в `analytics-config.js` не добавлен публичный идентификатор. Текст брифа, имя пользователя и другие персональные данные не передаются.

| Событие | Когда срабатывает | Что помогает понять |
| --- | --- | --- |
| `page_viewed` | Открыта страница | Посещаемость страниц и языков |
| `pricing_opened` | Открыты пакеты и цены | Интерес к коммерческим условиям |
| `projects_opened` | Открыты проекты | Интерес к подтверждениям опыта |
| `selector_started` | Начат подбор решения | Вход в основной сценарий |
| `selector_goal_selected` | Выбрана цель | Тип востребованной задачи |
| `selector_completed` | Подготовлен бриф | Завершение подбора |
| `solution_opened` | Открыт состав услуги | Интерес к конкретному направлению |
| `contact_opened` | Открыт контакт | Намерение связаться |
| `brief_copied` | Скопирован бриф | Сильное намерение связаться |
| `instagram_opened` | Открыт Instagram после копирования | Переход к контакту |
| `generate_lead` | Нажата главная контактная кнопка | Основная конверсия |

## Подключение

1. Создать бесплатный проект Microsoft Clarity и вставить только его Project ID в `analytics-config.js`.
2. При необходимости добавить GA4 Measurement ID вида `G-XXXXXXXXXX` для воронок и событий.
3. Cloudflare Web Analytics можно включить через публичный token, если сайт будет обслуживаться через Cloudflare.
4. После подключения проверить Network и real-time отчёт. В событиях допустимы только заранее заданные категории; свободный текст формы не используется.
