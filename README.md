# foxnaim — portfolio

Портфолио full-stack разработчика: сайты, CRM, SaaS, Telegram-боты и AI-автоматизация. Сайт работает без сборки и публикуется на GitHub Pages.

**Сайт:** [foxnaim.github.io/portfolio](https://foxnaim.github.io/portfolio/)

## Локальный запуск

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).

## Что внутри

- Одноэкранная главная с локальным видео, адаптивной навигацией и доступными диалогами.
- Отдельные индексируемые страницы четырёх услуг, каталога из 17 проектов, процесса работы, информации о разработчике и контакта.
- Уникальные title и description, canonical, Open Graph, Twitter Cards, JSON-LD, `sitemap.xml`, `robots.txt` и web manifest.
- Локальные шрифты, постер, видео и социальное превью без внешних CDN-зависимостей.
- Автоматическая публикация через GitHub Actions.
- Автоматическое уведомление поисковиков через IndexNow после публикации.

## Где менять содержимое

| Файл | Содержание |
| --- | --- |
| `index.html` | Главный экран, проекты, обо мне, контакт и SEO главной |
| `main.js` | Диалоги, описания услуг, видео и копирование брифа |
| `styles.css` | Дизайн и адаптивность главной |
| `scripts/generate-seo-pages.py` | Контент отдельных SEO-страниц и генерация sitemap/robots |
| `site.config.json` | Публичный URL, бренд и социальные ссылки |
| `assets/` | Логотип, фото, постер, видео, иконки и OG-превью |

После изменения URL или контента SEO-страниц выполните:

```sh
python3 scripts/generate-seo-pages.py
```
