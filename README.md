# foxnaim — portfolio

Одноэкранное портфолио на HTML, CSS и JavaScript. Без сборки, фреймворка, зависимостей и серверной обработки заявок.

## Локальный запуск

Из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).

## Что внутри

- Главный экран с видео, точечным заголовком и четырьмя направлениями работы.
- Разделы «Проекты», «Обо мне», услуги и контакт открываются в диалогах. Ссылками `#work`, `#about`, `#contact` можно делиться; работают история браузера и Escape.
- Кнопка связи открывает Instagram. Необязательный текст заявки копируется в буфер обмена по нажатию. Автоматической отправки, сбора данных, cookies и аналитики нет.
- Мобильная навигация, клавиатурный фокус в диалогах, статичный фон при `prefers-reduced-motion` и ручная пауза видео.
- На очень низких экранах (до 520 px) включается прокрутка, чтобы не скрывать контент.

## Где менять содержимое

| Файл | Содержание |
| --- | --- |
| `index.html` | Тексты, имя, Instagram, GitHub и проекты |
| `main.js` | Описания услуг, диалоги, управление видео и буфером обмена |
| `styles.css` | Цвета, типографика, композиция и адаптивность |
| `assets/` | Логотип, фото для раздела «Обо мне», постер и оптимизированное видео |
| `fonts/` | Резервный шрифт Geist Pixel Circle с лицензией OFL |

В качестве имени используется **foxnaim**: в предоставленных материалах встретились разные имена. Контакт из скриншота — **@yan._.pavlov**. Перед публичным запуском подтвердите имя и контакт.

Проекты взяты из публичных README GitHub: Tact (`World-Time-Frontend`), NeuroNotes, Dev-flow, Luki_lu-Shop. Обложки созданы для портфолио и не выдаются за скриншоты приложений. Коммерческие результаты, клиенты и сроки не выдумывались.

## Ассеты и внешние подключения

- Исходный ролик из предоставленного референса: [CloudFront MP4](https://d8j0ntlcm91z4.cloudfront.net/user_38xzZboKViGWJOttwIXH07lWA1P/hf_20260809_012548_ef22562c-c0ae-4816-ad9d-f8922af4e6a7.mp4). Он указан первым источником. Если CDN не отвечает или загрузка занимает больше 2,2 секунды, используется локальная сжатая копия того же ролика `assets/background.mp4`. Постер — кадр из него. Права на публикацию видео необходимо подтвердить у его владельца до публичного запуска.
- Inter загружается из Google Fonts, BubbledotICG-FinePos — из OnlineWebFonts, как в референсе. Атрибуция OnlineWebFonts доступна в разделе «Обо мне». Перед коммерческой публикацией проверьте права на этот шрифт; при необходимости используйте локальный Geist Pixel Circle под OFL.
- Geist Pixel Circle: [vercel/geist-font](https://github.com/vercel/geist-font), лицензия в `fonts/OFL.txt`.
- Логотип foxnaim и иллюстрации обложек выполнены средствами SVG/CSS; Font Awesome не требуется.

Внешние шрифты, видео и ссылки передают соответствующим провайдерам обычные сетевые сведения при обращении к ним. Текст из поля заявки не передаётся.

Исходники: [foxnaim/portfolio](https://github.com/foxnaim/portfolio). Сайт подготовлен для локального просмотра; публичный хостинг и домен не настраивались.
