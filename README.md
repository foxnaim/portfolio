# foxnaim — portfolio

Портфолио full-stack разработчика: сайты, CRM, SaaS, Telegram-боты и AI-автоматизация. Сайт работает без сборки и публикуется на GitHub Pages.

**Сайт:** [foxnaim.github.io/portfolio](https://foxnaim.github.io/portfolio/)

## Локальный запуск

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).

## Что внутри

- Одноэкранная главная с локальным видео, адаптивной навигацией, пятью вопросами подбора решения и доступными диалогами.
- Полный интерфейс главной переключается между русским, английским и казахским без перезагрузки и переадресации.
- 35 индексируемых URL: услуги, 18 проектов с фильтрами, расширенные кейсы, четыре коммерческие страницы под конкретные задачи, пакеты и цены, журнал разработки, сравнение форматов, процесс работы, статьи, контакты и страница для партнёров.
- Журнал Build with Yan использует четыре лёгкие локальные WebP-обложки из публичных Reels без Instagram SDK, iframe и автоматической загрузки видео.
- Open-source кейс Build with Yan Skills связывает публикацию, подробный разбор и репозиторий с тремя Agent Skills.
- Три масштаба разработки с ориентиром по бюджету, сроку, составу и этапной оплатой 30 / 40 / 30.
- Demo Lab с четырьмя локальными сценариями: CRM, AI-квалификация, онлайн-запись и Telegram-магазин.
- Три бесплатных интерактивных чек-листа, которые сохраняют прогресс только в браузере.
- Статический снимок GitHub-активности обновляется во время публикации и не зависит от публичного API в браузере посетителя.
- PWA-режим с web manifest, service worker и запасной страницей для работы без сети.
- Английская и казахская точки входа с корректными `hreflang`, отдельными метаданными и структурированными данными.
- Уникальные title и description, canonical, Open Graph, Twitter Cards, JSON-LD, `sitemap.xml`, `robots.txt` и web manifest.
- Локальные шрифты, постер, видео и социальное превью без внешних CDN-зависимостей.
- Автоматическая публикация через GitHub Actions.
- Автоматическое уведомление поисковиков через IndexNow после публикации.
- События основной воронки и готовые адаптеры для бесплатных Microsoft Clarity, GA4 и Cloudflare Web Analytics; внешние запросы выключены до добавления публичного ID.

## Где менять содержимое

| Файл | Содержание |
| --- | --- |
| `index.html` | Главный экран, проекты, обо мне, контакт и SEO главной |
| `main.js` | Диалоги, подбор решения, видео-превью и подготовка брифа |
| `i18n.js` | Полные переводы главной страницы RU / EN / KZ |
| `catalog.js` | Фильтры каталога проектов |
| `demo-lab.js` | Интерактивные сценарии Demo Lab |
| `resource-checklist.js` | Прогресс, сохранение и сброс чек-листов |
| `github-activity.json` | Готовый снимок публичной активности GitHub |
| `analytics-config.js` | Публичные ID аналитики; пустые значения отключают внешние запросы |
| `analytics.js` | События воронки без текста формы и персональных данных |
| `docs/analytics-tracking-plan.md` | Карта событий и инструкция подключения |
| `styles.css` | Дизайн и адаптивность главной |
| `seo-pages.css` | Дизайн внутренних страниц, кейсов и инструментов |
| `scripts/generate-seo-pages.py` | Контент отдельных SEO-страниц и генерация sitemap/robots |
| `scripts/update-github-activity.py` | Обновление GitHub-снимка во время публикации |
| `sw.js` | Офлайн-кеш и запасная навигация PWA |
| `site.config.json` | Публичный URL, бренд и социальные ссылки |
| `assets/` | Логотип, фото, постер, видео, иконки, обложки журнала и OG-превью |

После изменения URL или контента SEO-страниц выполните:

```sh
python3 scripts/generate-seo-pages.py
```
